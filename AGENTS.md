# link-shortener — agent instructions

Our company-wide link shortener, served at **go.symprex.com**. Nuxt 4 on Cloudflare, shadcn-vue components, Tailwind, i18n.

## This is a fork

Upstream is [miantiao-me/Sink](https://github.com/miantiao-me/Sink). A change that could be made the way upstream would make it is cheaper to carry forward, so prefer the upstream shape unless there is a Symprex reason not to. `LICENSE`, `CODE_OF_CONDUCT.md` and `renovate.json` are upstream's.

## Nothing runs on a pull request

There is no test suite here and no CI workflow. `pnpm typecheck` and `pnpm lint` are the whole of what can be checked, and neither of them proves behaviour.

So a change is handed over with what a person should click, not with a claim that it is verified. Do not report a lint pass as verification.

ESLint is also the formatter — the antfu config carries the stylistic rules and `lint-staged` runs `eslint --fix`. There is no Prettier or oxfmt step to look for.

## `pnpm typecheck` needs a prepared Nuxt

It is `nuxt typecheck`, and it reads generated types from `.nuxt`, which `postinstall` creates via `nuxt prepare`. On a fresh clone run `pnpm install` first — otherwise it fails on missing generated types and the error points nowhere near your change.

## Components are generated

`app/components/ui/` is shadcn-vue, generated by the shadcn CLI against `components.json`. Treat it as generated: add a wrapper beside it rather than editing it in place. `shadcn-nuxt` runs with an empty prefix, so those components are auto-imported and need no import statement.

`app/components/spark-ui/` is a second, hand-written set and is not generated.

## The Symprex workflow

Repository conventions live in `.symprex/config.json` — read them there rather than inferring them.

The stages are human-invoked: `/symprex:plan`, `/symprex:execute`, `/symprex:complete`. `.symprex/STATE.md` is the session's own scratch file, gitignored and ephemeral; it is not a record of anything.

`.claude/skills/` and the generated rules under `.claude/rules/` and `.github/instructions/` are **vendored** from [Symprex/ai-engineering](https://github.com/Symprex/ai-engineering) and kept level by `.github/workflows/sync-agent-skills.yml`. Do not edit them here — the change belongs upstream, and a local edit is overwritten by the next sync.
